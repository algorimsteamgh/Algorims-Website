# Algorims visual rules

- `design-options/ref-light-theme.webp` is the **light homepage layout and palette reference**: centered statement hero, thin framed canvas and dividers, white ground, charcoal text, sparse deep violet, a single large system diagram, and a restrained proof strip.
- **Use ImageGen for all new illustrations and for illustration revisions.** Integrate the generated raster image as a website asset. Use the artwork displayed on the **Products page** (`src/pages/products/index.astro`) as the sole style reference for illustration prompts. Choose the most relevant product artwork and pass it to ImageGen as a reference image. Other pages may inform layout and interaction when requested.
- Illustrations must show a real relationship such as inputs → Algorims system → outcomes. Keep text outside the artwork when possible and give meaningful images an accessible text alternative. Keep essential labels readable on mobile.
- Do not present the Microsoft, Google, IBM, Oracle, or SAP logos from the homepage reference mockup as actual Algorims partners or clients without evidence.

These rules supersede the older planning status and illustration interpretation in `DESIGN_SYSTEM_REVAMP.md` for implementation work.
