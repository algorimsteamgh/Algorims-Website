The Problem

Your L1 desk is stuck between two bad options

Password resets, access requests, software installs — the same tickets, every day, while your team's actual expertise sits in a backlog. The obvious fix is automation. The trouble is most "IT chatbots" either can't really do anything beyond triage, or they execute changes through a shared admin account with no rollback — which is a bigger risk than the ticket backlog.

OpsIQ resolves the routine tickets end-to-end, and treats anything touching identity, network, or bulk scope as a decision for a human — every time, by design.

  • ✓ Every ticket category scored into a tier, signed off by your IT Manager before go-live
  • ✓ No domain-admin credentials, ever — a scoped service account only
  • ✓ Grounding check before execution — never acts on a guess
Domain-Admin Access

Most AIOps tools ask for more access than they should

A shared admin login turns automation into the biggest single point of failure in your environment. OpsIQ's Active Directory actions run under a service account scoped to specific cmdlets only — password reset, account unlock, group membership — federated via SAML through AWS IAM Identity Center. Your AD stays the single source of truth.

Least privilege
Scoped to exact cmdlets, never a shared login
Full rollback
Multi-step runbooks roll back automatically on failure

The Platform

What OpsIQ actually does for your service desk

Classify what's being asked. Execute what's safe to execute. Escalate what needs a person. Control what's logged and where data lives.

🧠
Classify

Structured classification, never a hallucinated field

  • Amazon Bedrock (Claude 3.5 Sonnet) returns category, confidence score, and recommended playbook — structured output, not free text.
  • Grounding check against Bedrock Knowledge Bases before anything executes — a retrieval match, not a guess.
  • 47 ticket categories scored in the reference deployment; the top 10 already cover 82% of volume.
🛠️
Execute

Real fixes, run by AWS Systems Manager — not a custom script

  • AWS Systems Manager Automation runs the actual remediation runbook, with native multi-step rollback if any step fails.
  • Least-privilege service account — AD operations limited to specific cmdlets, federated via SAML, no domain-admin credentials anywhere.
  • VPC PrivateLink throughout — no traffic on the public internet.
🔏
Escalate

Three tiers, signed off before go-live — never assumed

  • Tier 1 fully autonomous and reversible; Tier 2 autonomous with IT-lead notification; Tier 3 pauses for human approval — bulk changes, firewall rules, domain changes.
  • Your IT Manager signs off the tiering, category by category, before anything goes live.
  • Escalations carry full AI-generated context — never a cold or blind transfer to L2.
🧾
Control

Every run logged, every identity protected

  • Immutable execution log — every automation run's inputs, outputs, and status written to DynamoDB and CloudTrail.
  • Bedrock Guardrails redact PII — name, employee ID, email, phone, IP — before anything is stored or logged.
  • Monthly quality review of a ticket sample, plus every low-confidence ticket, drives ongoing tuning — this is why accuracy keeps climbing.
